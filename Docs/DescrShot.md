🎯 Цель проекта: AI-помощник для планирования карьеры с персонализированными рекомендациями и треком прогресса.

💼 Какие бизнес-задачи закрывает:

Помощь в карьерном планировании
Персонализированные рекомендации
Отслеживание прогресса
Мотивация и поддержка
🛠️ Функциональные требования:

Онбординг:
Текущая должность
Желаемая цель (1-3-5 лет)
Навыки и зоны роста
AI генерирует:
Карьерный план
Навыки для развития
Курсы и ресурсы
Чек-лист задач
Еженедельный коучинг через диалог
Трекинг целей
Анализ рынка труда
Подготовка к интервью (mock)
Telegram-бот для чек-инов
⚙️ Технические требования:

Язык: Python
AI-помощник: Cursor (или аналог)
Backend: FastAPI
Frontend: Streamlit
БД: MongoDB
Библиотеки: openai, python-telegram-bot, langchain
Промпт: "Создай AI-коуча для карьеры с персонализацией и треком прогресса"
🔐 Дисклеймер по персональным данным: Личный проект. Шифрование данных.

💡 Подсказка для Cursor:

"Создай систему онбординга и профиля пользователя"
"Реализуй AI-генерацию карьерного плана"
"Добавь Telegram-бота для еженедельного коучинга"
