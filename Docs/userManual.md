# Руководство пользователя — Personal AI Coach

**Продукт:** персональный ИИ-коуч для карьеры (single-user).  
**UI:** https://aicareercoach.alexklyvibe.ru/  
**Telegram:** [@alexvibeaipersonalcoach_bot](https://t.me/alexvibeaipersonalcoach_bot)

Система ведёт **один активный карьерный трек**, строит план, разбирает вакансии/заказы (skill-gap), коучит по неделе, гоняет mock-интервью и принимает check-in из Telegram.

---

## 1. С чего начать

1. Открой UI по ссылке выше (или локально `http://127.0.0.1:8501`).
2. Слева в сайдбаре — разделы дашборда.
3. **Сначала «Онбординг»** → сохрани профиль и активируй трек.
4. Дальше по цепочке: **План → Рынок → Коучинг / Интервью**. Telegram — для быстрых check-in и коротких вопросов.

Без активного трека план, коучинг и интервью не заведутся — UI сам предупредит.

---

## 2. Карта дашборда (сайдбар)

| Раздел | Зачем |
|---|---|
| **Онбординг** | Профиль, цели (треки), переключение активного трека |
| **План** | AI-план 1/3/5 лет, задачи, % прогресса |
| **Рынок / Skill-gap** | hh / Kwork / ручной текст → разрыв навыков |
| **Коучинг** | Диалог с коучем + weekly check-in |
| **Интервью** | Mock interview + feedback |
| **Статус** | Health API / диагностика |

---

## 3. Онбординг

### Возможности

- Профиль: должность, желаемая роль, навыки, зоны роста, «о себе», часы в неделю.
- Несколько **треков-целей**, активен только один.
- Типы целей:
  - `employment` — устройство на работу
  - `side_income` — доп. заработок
  - `first_freelance_order` — первый заказ на фрилансе
  - `custom` — своя формулировка
- Кнопка **«Заполнить из LightRAG-профиля»** — seed профиля и трека «первые заказы» из личной базы (без дублей по type+title).
- **Upsert** при сохранении: тот же type+title не плодит клоны, а обновляет и активирует.

### Как пользоваться

1. (Опционально) «Заполнить из LightRAG-профиля».
2. Заполни форму «Профиль и цель» → **«Сохранить профиль и трек (без дублей)»**.
3. В блоке «Мои треки» смотри список; у неактивного жми **«Сделать активным»**.
4. Внизу — JSON активного трека (контроль, что сохранилось).

### Сценарий

> Хочу сфокусироваться на фрилансе, потом переключиться на найм.  
> Создаёшь трек «Первые заказы» → работаешь с ним → позже сохраняешь трек «Удалённый Python» и жмёшь «Сделать активным». История планов/check-in привязана к трекам.

---

## 4. План

### Возможности

- Генерация структурированного карьерного плана (горизонты, навыки, ресурсы, чек-лист).
- Список задач со статусами; кнопка **Done** (повторно не жмётся).
- Метрика **«Прогресс %»** по треку (доля выполненных задач).

### Как пользоваться

1. Убедись, что в онбординге есть активный трек.
2. **«Сгенерировать план»** — создаётся новая версия плана + задачи.
3. Читай summary и JSON плана.
4. Отмечай задачи **Done** по мере выполнения.
5. Смотри прогресс %.

### Сценарий

> После онбординга жмёшь генерацию → на неделе закрываешь 2–3 задачи → прогресс растёт → в коучинге/Telegram спрашиваешь «что дальше на этой неделе».

Повторная генерация = новый `plan_id` (версии не затирают смысл «истории», UI показывает последний план).

## 5. Рынок / Skill-gap

### Возможности

Три источника:

| Источник | Что делает |
|---|---|
| **hh** | Поиск вакансий через API hh.ru (нужен валидный токен приложения) |
| **kwork** | Read-only поиск проектов/заказов |
| **manual** | Вставка своего текста вакансии или ТЗ заказчика |

После выбора позиции — **Skill-gap анализ**: gaps / strengths / match score / roadmap относительно твоего профиля.

### Как пользоваться

**Manual (всегда доступен):**

1. Источник → `manual`.
2. Заголовок + текст → **Импорт**.
3. **Skill-gap анализ** → смотри отчёт.

**hh / kwork:**

1. Источник → `hh` или `kwork`.
2. Запрос (например `Python Telegram FastAPI`) → **Искать**.
3. **Выбрать** нужную карточку → **Skill-gap анализ**.

Если hh вернул пусто — приложение на модерации/нет токена; используй **manual** или kwork.

### Сценарий

> Нашёл вакансию на другом сайте → копируешь текст в manual → skill-gap → критичные пробелы тащишь в задачи плана или спрашиваешь коуча «как закрыть gap X за 2 недели».

## 6. Коучинг

### Возможности

- Чат с ИИ-коучем в контексте **активного трека** (и опционально LightRAG — пометка `[KB]` в ответе).
- История последних реплик в сессии UI.
- Форма **Check-in**: настроение 1–5, wins, blockers.

### Как пользоваться

1. Пиши в `chat_input` внизу — получишь ответ коуча.
2. Для weekly-ритуала заполни форму Check-in → **Сохранить**.

### Сценарий

> Воскресенье: check-in `4 | 3 отклика | нет времени вечером` → вопрос «что сделать на этой неделе под мой KPI» → коуч даёт 2–3 конкретных действия.

То же можно делать из Telegram (см. §8).

---

## 7. Интервью

### Возможности

- Mock interview под роль (текст).
- Несколько вопросов за раунд.
- Отправка ответов → structured feedback (оценка, слабые места, что подтянуть).

### Как пользоваться

1. Укажи роль (по умолчанию что-то вроде «Python / AI разработчик»).
2. **Старт mock interview**.
3. Ответь в полях под каждым вопросом.
4. **Отправить на оценку** → читай JSON/feedback.

### Сценарий

> Перед реальным собесом: роль = целевая вакансия с рынка → 1 раунд → по feedback закрываешь 1–2 слабых места в плане/резюме → повтор через неделю.

## 8. Статус

Служебный экран: ответ `GET /health` (API, Mongo, флаги окружения).  
Если «не работает» — сюда первым делом: должен быть `status: ok` / healthy.

---

## 9. Telegram-бот

Бот отвечает **только владельцу** (`TELEGRAM_OWNER_ID`). Чужие сообщения игнорятся.

| Команда / ввод | Действие |
|---|---|
| `/start` | Приветствие и список команд |
| `/status` | Health API + название активного трека |
| `/checkin` | Подсказка формата check-in |
| `4 \| wins \| blockers` | Сохранить check-in (цифра + две части через `\|`) |
| Любой другой текст | Коучинг-turn (короткий ответ + suggested actions) |

Пример check-in:

```text
4 | сделал 3 отклика | нет времени вечером
```

Если активного трека нет — бот скажет зайти в Streamlit-онбординг.

Worker периодически шлёт weekly-напоминание (напоминалка, не отдельный UI).

## 10. Сквозные сценарии

### A. Первый запуск (фриланс)

1. Онбординг → seed или ручной профиль → трек `first_freelance_order`.
2. План → сгенерировать → 2–3 задачи на неделю.
3. Рынок → kwork или manual ТЗ → skill-gap.
4. Telegram `/checkin` в конце недели.
5. Коучинг: «скорректируй фокус под gap».

### B. Подготовка к найму

1. Активируй трек `employment`.
2. hh (или manual вакансия) → skill-gap.
3. План → задачи под critical gaps.
4. Интервью → mock под роль вакансии.
5. Коучинг: разбор слабых ответов.

### C. Два фокуса без хаоса

Держи два трека в списке, переключай «Сделать активным». Не плоди дубликаты с тем же title — используй upsert/сохранение формы.

### D. Когда LLM/KB недоступны

- Без `OPENAI_API_KEY` работает StubLLM (smoke/демо, ответы шаблонные).
- `KNOWLEDGE_BASE_ENABLED=false` — коучинг без RAG (нет пометки KB).
- KB down при `true` — degraded mode, коучинг жив без 500.

## 11. Ограничения MVP (чтобы не ждать лишнего)

- Один пользователь, без регистрации.
- Автооткликов на hh/Kwork нет.
- Голоса в интервью нет (только текст).
- Telegram сейчас **polling**, не Mini App.
- Live hh зависит от одобрения приложения на [dev.hh.ru](https://dev.hh.ru) и токена в `.env`.
- Данные — личный проект; не клади в поля то, что нельзя хранить в своей Mongo.
